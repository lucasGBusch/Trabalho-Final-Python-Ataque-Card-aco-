# Trabalho Final - Doença Cardíaca

Trabalho da disciplina de Tópicos Especiais em Ciência da Computação.

## Objetivo
Desenvolver uma aplicação web utilizando Flask, Pandas e Machine Learning para analisar indicadores de doenças cardíacas.

## Tecnologias
- Python
- Flask
- Pandas
- Scikit-learn
- Matplotlib
